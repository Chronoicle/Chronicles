# Chronicles

Private World of Warcraft: Legion 7.3.5 (build 26972) server, based on [LegionCore](https://github.com/The-Legion-Preservation-Project/LegionCore-7.3.5) (see `README.LegionCore.md`).

This repository holds the server core with all Chronicles changes: premium system, custom scripts, crash fixes, creature scaling and dungeon/boss fixes.

Working on this repository (people and AI agents): the rules, server map, build/deploy steps and current status live on the server in `~/AGENTS.md`, `~/HANDOFF.md` and `~/CHANGES.md`. Every change is a commit with a message saying who changed what and why.
